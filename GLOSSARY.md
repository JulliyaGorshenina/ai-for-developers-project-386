# Глоссарий

Словарь предметной области сервиса бронирования звонков. Термины используются
в коде, тестах, задачах и документации без синонимов.

## Предметная область

| Термин | Определение |
| --- | --- |
| **Слот** | Промежуток времени длиной, равной длительности типа события, в который гость может записаться. Слоты генерируются из расписания владельца. |
| **Сетка слотов** | Последовательность моментов начала слотов внутри окна доступности. |
| **Шаг сетки** | Интервал между началами соседних слотов; равен длительности типа события. Сетка отсчитывается от начала окна. |
| **Окно доступности** | Непрерывный интервал внутри дня недели (день + время начала + время конца), задаваемый владельцем. Из окон складывается расписание. |
| **Расписание** | Набор окон доступности владельца на неделю. Хранится в БД; по умолчанию засевается при старте приложения. |
| **Тип события** | Вид встречи, который владелец публикует для гостей: id, название, описание и длительность в минутах. Гость выбирает тип при записи. |
| **Запись** (бронь) | Забронированный гостем слот с контактными данными (имя, email, комментарий). Запись занимает слот, пока не отменена. |
| **Гость** | Незарегистрированный пользователь, который выбирает слот и оставляет запись. |
| **Владелец** | Хозяин календаря: задаёт расписание и управляет предстоящими встречами. Доступ к его API — по токену. |

## Интерфейс

| Термин | Определение |
| --- | --- |
| **Главная страница** | Страница на `/` (`index.html`): рассказывает про сервис и ведёт на страницу записи. Точка входа приложения. |
| **Страница записи** | Страница на `/booking.html`: гость выбирает день и слот и оставляет заявку. |
| **Кабинет владельца** | Страница на `/admin.html`: расписание и предстоящие встречи владельца. |

## Технические термины

| Термин | Определение |
| --- | --- |
| **Токен доступа** | Значение `ADMIN_TOKEN`, передаваемое в заголовке `X-Admin-Token` для запросов к API владельца. |
| **`BOOKING_TZ`** | Часовой пояс, в котором генерируются слоты. В API слоты хранятся и отдаются в UTC, отображаются в часовом поясе браузера. |

## Тестирование

| Термин | Определение |
| --- | --- |
| **Юнит-тест** | Тест чистой логики без БД, сети и браузера (арифметика слотов, форматирование, валидация). |
| **Контрактный/API-тест** | Рукописный тест, кодирующий спецификацию, против реального FastAPI и SQLite (in-process). Объединяет «контракт» и «интеграцию/API». |
| **Тонкий e2e-дым** | Один сквозной тест happy-path в реальном браузере (Playwright, chromium). |
| **Дрейф-гард** | CI-проверка, что сгенерированные артефакты совпадают со спецификацией (`git diff` после генерации пуст). |
| **Снимок OpenAPI-схемы** | Зафиксированная в репозитории копия OpenAPI; база для проверки покрытия контрактных тестов. |
