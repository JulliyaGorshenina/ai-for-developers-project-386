# ADR 0001: Главная страница на корне, запись — на `/booking.html`

- **Дата:** 2026-10-22
- **Статус:** принято

## Контекст

Страница записи раньше отдавалась на `/` (`index.html`), а кабинет владельца —
на `/admin.html`. Появилось требование добавить главную страницу, которая
рассказывает про сервис и ведёт на страницу записи. Бэкенд раздаёт собранный
фронтенд через `StaticFiles(html=True)` (`backend/app/main.py`), поэтому
`index.html` автоматически обслуживается на корне.

## Решение

- Главная страница — `index.html`, отдаётся на `/`.
- Страница записи переехала в `booking.html`, отдаётся на `/booking.html`.
- Кабинет владельца остаётся на `/admin.html`.
- Все три страницы зарегистрированы как входные точки Vite в
  `frontend/vite.config.ts` (`rollupOptions.input`).

## Последствия

- Точка входа (`/`) описывает сервис; переход к записи — по явной ссылке.
- Существующие ссылки обновлены: главная → `/booking.html`, страница записи →
  `/` и `/admin.html`, кабинет владельца → `/` и `/booking.html`.
- Добавление новой HTML-страницы по-прежнему требует правки `input` в
  `vite.config.ts`.
