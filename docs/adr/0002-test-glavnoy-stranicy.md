# ADR 0002: Тест главной страницы по HTML, без DOM-окружения

- **Дата:** 2026-10-22
- **Статус:** принято

## Контекст

Главная страница (`index.html`) статична: её единственное поведение — ссылка на
страницу записи. Требуется тест, который проходит в CI. Существующие тесты
фронтенда (vitest, `src/format.test.ts`) работают в node-окружении без DOM и без
дополнительных зависимостей.

## Решение

Тест `frontend/src/home.test.ts` импортирует разметку как строку через
`import homeHtml from "../index.html?raw"` (типы `vite/client`) и проверяет:
наличие `<title>`, ссылку `href="/booking.html"` и описание сервиса.

## Последствия

- Новые dev-зависимости (jsdom, testing-library) не добавляются,
  `package-lock.json` не меняется, CI остаётся зелёным.
- Тест проверяет контракт страницы (ссылка на запись + описание), а не поведение
  в браузере. Если у главной появится интерактивность, стоит пересмотреть
  решение в пользу DOM-теста.
